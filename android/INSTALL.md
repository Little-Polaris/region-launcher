# Region Launcher Android 开发验证包

版本：0.1.0-dev.2。支持 Android 13 及以上，包含 ARM64 与 x86_64。

当前仅通过编译、配置单元测试、静态检查和安装包结构/签名检查。
尚未在 Android 系统或 vivo X300 上完成安装、真实流量隔离、DNS/UDP/IPv6、退出恢复和工作资料断网保护的运行验收。

## 使用方式

1. 安装 APK。首次连接需要手机确认 VPN 权限；通知权限用于展示连接和失败信息。
2. 如需把环境内外的同一应用分开，先创建独立工作资料，再打开带工作标记的 Region Launcher，在该资料中安装目标应用。应用登录状态和私人数据不会从个人资料自动复制。
3. 导入 HTTPS 订阅、分享链接或 Clash YAML/JSON，选择节点。订阅地址和节点密钥保存在应用私有目录，不进入导出的日志。
4. 添加需要联网的应用，点击“启动所选应用”。启动前先通过指定节点请求 HTTPS 检测站，再检查环境内出口是否一致；失败时不自动打开目标应用。
5. “检测并修复”仅在点击或启动应用时执行；没有定时、随机检测。代理请求或环境内转发连续失败后，尝试重建内核连接，同一进程内保留 VPN 接口；一分钟内不重复修复。超时检测会取消并关闭相应连接。
6. 在本应用创建的工作资料中，连接时会启用该资料的系统断网保护。未选中的工作应用也会断网，个人资料不受此策略管理。主动停止会解除该资料的保护。
7. 导出日志前可在“查看日志”中检查内容。日志包含检测站、出口 IP、耗时、状态和异常类型，不记录完整节点配置。

## 与 Windows 版不同的地方

- 普通个人资料模式按应用 UID 接管：同一资料中，无论从哪里打开所选应用，它都会使用此 VPN。不能按“从哪个启动器打开”区分。
- 工作资料是独立应用数据空间，不是虚拟机。厂商系统能否创建和运行工作资料需要真机验证。
- 一个用户资料同时只能运行一个 VPN。本应用在发现同资料已有 VPN 时停止连接请求，避免直接替换它；已有工作资料也不会被删除。
- 未 Root 时，不能强制更改任意其他应用的时区和地区。应用语言仅提供系统支持的每应用语言入口，不能保证每个应用支持。
- 不设置手机全局代理、DNS、地区或时区。Android 文件权限和应用私有数据边界照常适用。
- 个人资料模式没有系统级断网锁定；VPN 被终止后，所选应用可能恢复系统网络。个人资料里的系统“阻止不使用 VPN 的连接”可能影响该资料其他应用，不要把它当成只针对所选应用的功能。
- 本应用不能强制结束其他应用。停止连接前应先退出需要继续保护的应用。
- 如果目标应用把链接交给其他应用，例如授权浏览器，应将该资料内的浏览器也加入选择列表。
- 软件会保留代理协议对 UDP 的能力限制；不支持 UDP 的节点不会改走直连。
