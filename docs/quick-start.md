# 使用指南

## 首次运行

1. 安装 .NET 10 Desktop Runtime x64，将发布 ZIP 完整解压到可写目录。支持中文等 Unicode 路径。
2. 运行根目录“安装或更新后台服务.cmd”，完成管理员确认。后台服务安装后，日常启动使用普通用户权限即可。
3. 打开 `app/RegionLauncher.exe`，点击“独立代理配置…”。填写节点，或通过“机场订阅 / 选节点…”导入订阅并选中一个节点，再“校验并保存”。详见 [代理配置](proxy-settings.md) 和 [订阅导入](subscriptions.md)。
4. 点击“添加…”，保存软件名称、程序路径和启动参数，设置该软件的国家和地区、语言、时区。
5. 从“运行软件”列表选择软件，点击“启动所选程序”。联网检测通过后开始运行；已有环境时，新启动的软件加入当前环境，保留各自的地区设置。

同一次运行共用代理节点。修改地区选项对该软件下次启动生效，正在运行的软件保留原设置。

## 窗口、托盘和日志

关闭窗口会隐藏到托盘，程序与代理继续运行；再次打开启动器会恢复已有窗口。

从托盘选择“退出（结束全部运行）”会结束本启动器的运行组、释放自有代理端口并退出。请先保存受控应用中的文件。

联网异常时点击“检测并修复”。启动新程序前也会执行检测，实际联网连续失败才按条件重连自有代理。正常运行期间不执行定时或随机检测。通过“打开日志”查看检测、重连、代理路由和程序输出，详见 [联网检测](connectivity.md)。

## 升级与迁移

1. 保存文件，从托盘退出旧版启动器。
2. 备份 `app/data`，再用新发布包覆盖程序文件。该目录保存软件列表、节点、订阅和可能存在的浏览器资料，请妥善保管。
3. 按 Release 说明判断是否需要更新后台服务。
4. 如果移动了程序或浏览器资料目录，请检查软件列表中的绝对路径与启动参数。

软件列表保存于 `app/data/applications.json`。配置字段见 [软件列表](applications.md)；浏览器资料与授权链接配置见 [授权浏览器](link-browser.md)。

## 发布包内容

| 路径 | 内容 |
| --- | --- |
| `app/` | 启动器、运行模块、代理内核及许可证 |
| `install/` | 后台服务安装文件 |
| `docs/` | 功能说明与测试记录 |
| `SHA256SUMS.txt` | 程序和安装文件的 SHA-256 校验清单 |

节点及订阅由使用者自行配置，`app/data` 中的私人配置不包含在发布 ZIP 内。
