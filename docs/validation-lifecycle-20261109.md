# 2026-11-09 启动、退出隔离修复验收

版本：0.3.0-alpha.2。修复提交：806ab0d。

## 修复内容

原网络引擎停止时，先禁止收发并关闭 WinDivert 句柄，再等待处理线程结束。全局捕获队列也包含环境外程序的数据包，因此队列中及线程正在处理的数据包可能丢失；历史退出日志中的 WinDivertSend error 6 与该顺序吻合。

现在先停止接收新包，保留发送句柄和进程归属表，让处理线程读完现有队列，再关闭句柄并清理状态。启动时处理线程创建失败，也走同一排空路径。没有更换 WinDivert 驱动，没有为浏览器设置代理或 DNS。

这确认并修复了一个可能影响外部连接的退出缺陷，但无法追溯证明它是之前“重启代理才恢复”的持续断网的唯一原因。
