# 后台服务与验收状态

后台名：`RegionLauncherNetwork`。安装位置：`C:\Program Files\RegionLauncherNetwork`。普通启动器通过本机命名管道请求创建环境；目标应用由普通权限启动器启动。后台仅运行受保护目录内固定的工作进程。

接口不接受程序路径、脚本、命令行、任意 DLL 或文件写入路径。安装时绑定当前用户 SID；拒绝远程管道访问、低完整性客户端、其他用户、无效协议、非本机 DNS、无效端口、非用户拥有的进程组及非空/可逃逸进程组。环境身份来自实际管道客户端进程和其持有的 Job 句柄，不依靠可执行文件名称。只允许一个网络环境，环境内可加入多个程序。

服务和工作进程使用独立进程；每次工作进程只继承明确列出的句柄。启动器退出、停止请求、服务正常退出或服务进程消失时，工作进程结束环境进程组。启动器也监视工作进程退出。尚未证明崩溃瞬间完全无泄漏。

服务空闲时不打开 WinDivert。安装器将文件设为 SYSTEM/管理员可写、普通用户只读；驱动签名及包中四个固定文件的 SHA-256 在安装前后核对。已加载且内容相同的驱动不覆盖。服务文件更换仍需管理员确认，日常会话创建通过服务执行，无须 runas。

转发引擎使用本机 TCP 34010、UDP 34011 接收重定向数据；安装器只为受保护的 `RegionNetworkService.exe` 和这两个端口创建入站规则，名称为 `RegionLauncherNetwork-TCP/UDP`。这些规则不适用于其他程序。卸载删除这两条规则及用户态服务，保留文件和日志，不删除可能被其他软件使用的 WinDivert 驱动。系统代理、DNS、路由和 IPv6 网卡绑定不修改。

## Windows 参数选择

国家由 EnumSystemGeoID/GetGeoInfoW 枚举（本机 250 项），语言由 EnumSystemLocalesEx/GetLocaleInfoEx 枚举（605 项），时区来自 Windows 时区列表（144 项）。保存实际 GEOID、区域代码、语言名称、Windows 时区 ID 和自动夏令时开关。默认 US/244、en-US、Pacific Standard Time、自动切换。

美国冬夏边界、关闭自动切换、父子进程、文件访问及组外设置不变已通过。德国/德语、日本/日语、印度/印地语的不同 Windows 参数已通过父子进程测试。界面默认值经绘制预览确认；完整浏览器和 Claude Desktop 操作未验收。应用自带地区库、预先存在的单实例程序、系统服务代发仍需要单独验证。

## 验证入口

后台安装入口为发布目录下的“安装或更新后台服务.cmd”。若双击后看不到 Windows 管理员提示，先关闭等待中的安装窗口，再右键该文件选择“以管理员身份运行”（Windows 11 可能需先选“显示更多选项”）。使用当前登录用户的管理员身份；安装会绑定执行用户。已经取得管理员权限时直接执行固定安装脚本，不再重复请求提升。窗口会保留安装结果，失败记录写入 `evidence/service-时间.json`。这一步仍需 Windows 授权，不会绕过系统权限控制。

从普通权限终端设置 `REGION_TEST_BIN` 为 `build/service-bin`：

```
python -X utf8 tests/test_service.py
pwsh -NoProfile -File scripts/verify_unified.ps1 -BinDirectory ./build/service-bin
python -X utf8 tests/test_locale.py
dotnet run --project tests/UiEntryPoint -- build/service-bin/RegionLauncher.dll
```

网页目标是实际访问 https://ip.net.coffee/claude/ 并记录检测结果。不得将 API 请求或离屏界面预览视作网页验收，不修改网页检测逻辑、浏览器专用网络设置或分数。IP 信誉与历史记录可能需要更换上游出口，运行环境设置不能改变第三方的历史数据库。

构建、下载、测试、打包默认使用 `build/service-bin`。完整验证入口会先检查后台运行状态和两个转发端口许可，再运行普通权限服务接口、DNS、TCP/UDP、外网对照测试。后台停止时的提前退出已实测，不启动任何测试应用，也不请求提权。

发布包包含通用客户端和独立的后台安装/卸载入口；后者将后台部署到受保护目录。已在独立打包目录运行 `tests/test_package.py`，确认运行依赖完整、包内后台文件及发布校验清单匹配、不包含私有节点配置。该检查不能替代后台安装、实际联网或网页验收。
