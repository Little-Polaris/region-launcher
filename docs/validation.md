# 本机验证记录

## 0.1.1 文件选择修复（2026-11-04）

界面入口原先缺少 `[STAThread]`，未满足 Windows 文件选择窗口的线程要求。已改为显式 STA 入口，并给文件选择窗口指定主窗口作为所有者。

构建检查通过。`dotnet run --project tests/UiEntryPoint -- <RegionLauncher.dll>` 检查实际发布程序集的入口：0.1.0 失败，0.1.1 通过。本次桌面控制工具初始化报“failed to write kernel assets: 系统找不到指定的路径”，因此尚未完成实际点击、取消与文件选择验证。下方网络和浏览器结果来自 0.1.0，本次没有重跑。

## 0.1.0 环境验证

日期：2026-11-04（北京时间）。版本：Region Launcher 0.1.0 环境验证版。

测试对象是自带的原生测试程序和本机 Chrome。**未下载安装或登录 Claude Desktop，结果不代表 Claude 已完成适配。**

| 检查 | 结果与证据 |
| --- | --- |
| 构建 | Visual Studio 2026 C++、.NET 10；原生模块与 Windows 界面编译成功 |
| 网络驱动 | 官方 WinDivert 2.2.2-A 归档；WinDivert64.sys 的 Authenticode 状态为 Valid |
| 美国地区和语言 | 父子测试进程均返回 `en-US / US / GEOID 244` |
| 自动冬夏时间 | 洛杉矶冬季 UTC−8，夏季 UTC−7 |
| 春季切换边界 | 2026-03-08：本地 01:59 → 03:00 |
| 秋季切换边界 | 2026-11-01：本地 01:59 → 01:00 |
| 关闭自动切换 | 冬夏均为 UTC−8；两处切换边界均不跳时 |
| 宿主机文件 | 测试进程直接创建并写入宿主机测试目录文件，内容校验成功 |
| 宿主机设置 | 环境外程序前后读取的地区、语言、时区保持一致 |
| 同一程序 TCP 分流 | 选中实例收到本机模拟代理的 `PROXY` 响应，同时运行的环境外实例收到直连服务的 `DIRECT` 响应 |
| 同一程序 UDP 分流 | 同上；使用 SOCKS5 UDP ASSOCIATE 模拟服务 |
| 子进程联网 | 由目标程序创建的子进程归入同一网络组，收到代理响应 |
| 普通代理拒绝 | SOCKS5 返回连接拒绝后，组内实例连接失败，没有收到直连服务响应；组外实例仍能直连 |
| 普通权限目标程序 | 测试脚本和目标程序以普通用户权限启动，只有网络引擎申请管理员权限；分流测试通过 |
| Chrome 页面时区和语言 | 页面 JavaScript 返回 `America/Los_Angeles`、`en-US`，冬季偏移 480 分钟、夏季 420 分钟 |
| Chrome 固定标准时间 | 页面返回 `Etc/GMT+8`，冬夏偏移均为 480 分钟 |
| 浏览器加入已运行环境 | 第二个启动请求加入现有进程组，Chrome 本地页面测试通过 |
| 浏览器远端域名解析 | 模拟 SOCKS5 服务收到 `region-test.invalid` 域名请求；不依赖本机 DNS 解析该域名 |
| 同时运行的外部 Chrome | 独立测试资料目录中的外部实例保持 `zh-CN / Asia/Shanghai`，本机 HTTP 访问走直连 |
| 真实代理出口抽查 | 经 127.0.0.1:7890 请求 Cloudflare 连接诊断，返回 `loc=US`、`colo=LAX`；只表示当次出口国家和接入点，不能证明节点固定在洛杉矶或具有某类 IP 信誉 |
| 界面 | 已检查本机绘制预览，主要配置、按钮与运行记录可见 |

所有分流测试目标均为本机模拟服务。测试没有接触账号、Claude 登录或用户现有浏览器资料。

尚未覆盖：Claude Desktop、Edge 实测、任意应用的单实例复用、外部默认浏览器回调、系统服务代发、普通程序全部 DNS 路径、IPv6/分片/网络切换、代理引擎崩溃时的无缝断网保证、WebRTC 泄漏实测、完整 GPU/外设兼容性。程序保留原有文件权限不等于每种应用都经过兼容性测试。

可复现测试脚本位于源码包 `tests/`。测试记录只对该版本及本机条件成立。
