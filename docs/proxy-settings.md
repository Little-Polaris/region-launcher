# 独立代理配置

主窗口点击“独立代理配置…”。已有配置会自动加载；首次使用请先选择协议。

| 协议 | 主要填写项 |
| --- | --- |
| Hysteria2 | 服务器地址、端口、密码、服务器名 SNI（如需要） |
| VLESS | 地址、端口、UUID、TLS 与服务器名；Reality、flow 等放入高级选项 |
| VMess | 地址、端口、UUID、加密方式（默认 auto）、TLS；alterId 等放入高级选项 |
| Trojan | 地址、端口、密码、服务器名 SNI |
| Shadowsocks | 地址、端口、密码、加密方式；插件参数放入高级选项 |
| TUIC | 地址、端口、UUID、密码、SNI；使用 v4 时在高级选项填写 token |
| AnyTLS | 地址、端口、密码、服务器名 SNI |

服务器地址支持 IPv4 或域名。本地端口默认 17890，不要使用宿主代理的 7890。TLS 证书验证默认开启；只在节点确有要求时选择跳过验证。

“高级选项”接收一个 JSON 对象，格式采用 Mihomo 节点字段，例如 `network`、`ws-opts`、`grpc-opts`、`reality-opts`、`alpn`、`obfs`。不填写时保留 `{}`。导入后这些额外字段会保留；切换协议会清空协议相关的凭据及高级选项，请重新填写。TLS/传输字段可参考 [Mihomo TLS](https://wiki.metacubex.one/config/proxies/tls/) 与 [传输层](https://wiki.metacubex.one/config/proxies/transport/) 文档。

“导入 JSON…”支持单个 Mihomo 节点对象，或只含一个 proxies 节点的 JSON 配置，包括原版的 data/private/proxy.json。只导入节点和独立端口，路由、DNS、监听范围由启动器生成。当前不支持 YAML、订阅地址、分享链接或多节点列表。

“校验配置”由随包的 Mihomo 内核检查格式及参数，不连接节点，也不证明节点在线。“校验并保存”先完成同样检查，再替换本地配置；已有文件备份到 data/private/proxy.json.bak。校验失败保留原文件。配置及备份含节点凭据，不要分享；压缩包排除整个 data 目录。

保存会结束启动器自己创建的旧代理内核，新配置在下一次检测或启动时使用。“检测代理”启动独立内核并检查本地 SOCKS5 握手，仍不代表目标网站可访问。环境运行期间不能编辑节点，先保存环境内文件并结束本次运行。

所有目标使用固定出口，网站 DNS 经该节点访问加密解析器，IPv6 保持禁用。仅监听本机地址，不打开系统 TUN，不修改宿主代理、DNS、路由或网卡设置。远程节点本身使用域名时，通过指定的加密解析器解析节点地址，这是连接节点前的引导解析。
