# 机场订阅与多节点

1. 在主窗口点击“独立代理配置…” → “订阅 / 选节点或组…”。已有本地配置文件时，点击“导入文件…”。
2. 粘贴机场的 HTTPS 订阅链接，优先选择机场提供的 Clash / Mihomo 格式。
3. 默认通过本机 127.0.0.1:7890 下载。若链接可以直连，取消勾选“通过本机代理下载”。这只决定订阅下载路径，不修改宿主机代理，也不决定选中节点的流量分流。
4. 点击“获取 / 更新节点”。列表显示可选节点及故障切换组，可搜索“US Auto”或协议名。
5. 点击“使用所选项”，返回配置窗口后点击“校验并保存”。更新订阅与选择列表项目只更新待保存配置。

后续重新打开该窗口，会显示本机缓存和上次选择。获取订阅需要手动更新。运行期间须先结束环境再更换代理配置。

自动故障切换支持直接引用两个或更多有效远程节点的 Mihomo `fallback` 组，节点顺序沿用原配置。Mihomo 每 60 秒探活，按顺序选择第一个可用节点。组成员为内置直连、其他组、外部提供者，或缺少可用节点时，该组会被跳过。切换后的新连接使用新的出口，已有长连接可能需要由应用重连。

支持格式：Clash/Mihomo YAML（含 proxies 的完整配置或节点列表）、JSON、Base64 包裹的分享链接列表，以及明文分享链接列表。支持七种协议的常见链接：Hysteria2/hy2、VLESS、VMess、Trojan、Shadowsocks、TUIC、AnyTLS。VLESS/VMess/Trojan 的常见 TCP、WebSocket、gRPC 参数及 VLESS Reality 参数可解析；分享链接有未识别参数时不擅自丢弃后导入，该项会跳过，建议改用 Clash/Mihomo 格式。Shadowsocks 分享链接的插件扩展、XHTTP 分享链接和仅含外部 proxy-providers 的配置不在当前范围内。

列表会提示已解析及跳过项数。不支持的协议、链式代理、本地回环节点、无效字段等不会成为可选项。保留订阅中的节点参数，不导入机场的 TUN、系统代理、监听地址、DNS 或分流规则。节点名称不等于真实地理位置，选择后仍需实际检测出口。

链接输入框隐藏内容。确认选择时，订阅链接和解析出的可选项保存在 app/data/private/subscription.json；当前生效的代理配置保存在 proxy.json。两个文件及备份都含敏感信息，打包排除整个 data 目录。下载只访问订阅地址及其 HTTPS 重定向，不使用第三方在线转换服务。下载有 30 秒超时、4 MB 限制和取消功能；失败保留原列表及当前代理配置。

## 本次验证

- YAML、JSON、Base64、明文 URI 多节点解析；保留数字形密码及嵌套传输参数。
- 七种协议的样例解析后由随包 Mihomo 完成配置校验，包含混合有效/不支持节点列表。
- 下载测试使用可控 HTTP 响应，覆盖读取、取消、过大响应、HTTPS 降级拒绝和错误信息不包含订阅令牌。
- 测试界面的筛选、选择指定节点、缓存写入和重新打开恢复选择；校验保存、旧节点兼容性及基础界面回归继续通过。
- 已查看布局渲染。实机窗口能读取控件，但电脑操作工具无法激活窗口，未将离屏测试视为真实鼠标验收。
- 本次没有提供真实机场订阅，未验证特定机场的鉴权、响应格式或各节点连通性。后台、驱动和宿主网络配置未调整。
